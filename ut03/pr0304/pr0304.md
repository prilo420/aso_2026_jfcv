## Ejercicio 1: Menú de operaciones matemáticas
Crea un script que muestre un menú con opciones para sumar, restar, multiplicar y dividir dos números. Debe pedir primero un operando, luego el otro y finalmente la operación a realizar. Usa case para realizar la operación seleccionada por el usuario.

```
# Creamos los valores para calcular
read -p "Primer número: " num1
read -p "Operación: " operacion
read -p "Segundo número: " num2

# Creamos el caso para las operaciones
case $operacion in
  +)
    resultado=$(("$num1" + "$num2"))
    echo "$num1 + $num2 = $resultado"
    ;;
  -)
    resultado=$(("$num1" - "$num2"))
    echo "$num1 - $num2 = $resultado"
    ;;
  /)
    # Para que no se divida entre 0
    if [ "$num2" -eq 0 ]; then
      echo "No se puede dividir entre cero."
    else
      resultado=$(("$num1" / "$num2"))
      echo "$num1 / $num2 = $resultado"
    fi
    ;;
  x)
    resultado=$(("$num1" * "$num2"))
    echo "$num1 * $num2 = $resultado"
    ;;
  *)
      echo "Escriba un operador."
    ;;
esac

## Ejercicio 6: Convertir temperaturas
Haz un script que convierta una temperatura ingresada por el usuario de Celsius a Fahrenheit, de Fahrenheit a Celsius o de Celsius a Kelvin, usando case para seleccionar la conversión deseada.

La fórmula para realizar las conversiones es:

* <b>Grados Fahrenheit = Grados Celsius * 1.8 + 32</b>
* <b>Grados Celsius = ( Grados Fahrenheit - 32) / 1.8</b>

```

#!/bin/bash

echo "----- Conversor de temperaturas -----"
echo "1. Celsius (°C) a Fahrenheit (°F)"
echo "2. Fahrenheit (°F) a Celsius (°C)"
echo "3. Celsius (°C) a Kelvin (K)"
read -p "Selecciona una opción (1-3): " opcion

read -p "Escriba la temperatura: " temp

case $opcion in
  1)
    # Fórmula: (C * 9/5) + 32
    resultado=$(( (temp * 9 / 5) + 32 ))
    echo "$temp°C son $resultado°F"
    ;;
  2)
    # Fórmula: (F - 32) * 5/9
    resultado=$(( ((temp - 32) * 5) / 9 ))
    echo "$temp°F son $resultado°C"
    ;;
  3)
    # Fórmula: C + 273
    resultado=$(( temp + 273 ))
    echo "$temp°C son $resultado K"
    ;;
  *)
    echo "Elija una opción (1-3)"
    ;;
esac

```

## Ejercicio 7: Estado del servicio
Escribe un script que reciba el nombre de un servicio (por ejemplo, “apache” o “mysql”) y, usando case, muestre opciones para iniciar, detener o reiniciar el servicio.

```

#!/bin/bash

read -p "Escriba el nombre del servicio (ej. apache2, mysql, ssh): " servicio

echo "--- Menú de servicios para $servicio ---"
echo "1. Iniciar servicio"
echo "2. Detener servicio"
echo "3. Reiniciar servicio"

read -p "Eliga una opción (1-3): " opcion

case $opcion in
  1)
    echo "Iniciando $servicio..."
    sudo systemctl start "$servicio"
    ;;
  2)
    echo "Deteniendo $servicio..."
    sudo systemctl stop "$servicio"
    ;;
  3)
    echo "Reiniciando $servicio..."
    sudo systemctl restart "$servicio"
    ;;
  *)
    echo "El servicio no existe o está mal escrito"
    ;;
esac

```

## Ejercicio 8: Conversión de unidades de longitud
Desarrolla un script que permita al usuario convertir metros a kilómetros, metros a centímetros, o metros a milímetros, utilizando case para manejar cada opción de conversión.

```

#!/bin/bash

read -p "Escriba la distancia en metros: " metros

echo "Selecciona la conversión:"
echo "1. Metros a kilómetros (km)"
echo "2. Metros a centímetros (cm)"
echo "3. Metros a milímetros (mm)"
read -p "Elige una opción (1-3): " opcion

case $opcion in
  1)
    # Metros a Kilómetros
    resultado=$(( metros / 1000 ))
    echo "$metros metros equivalen a $resultado kilómetros."
    ;;
  2)
    # Metros a Centímetros
    resultado=$(( metros * 100 ))
    echo "$metros metros equivalen a $resultado centímetros."
    ;;
  3)
    # Metros a Milímetro
    resultado=$(( metros * 1000 ))
    echo "$metros metros equivalen a $resultado milímetros."
    ;;
  *)
    echo "Eliga una opción (1-3)"
    ;;
esac
