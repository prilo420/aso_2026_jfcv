## 3.Configuracion del acceso remoto a los hosts
* Deshabilitamos el firewall de windows usamos el siguiente comando en los servidores core
````Set-NetFirewallProfile -Profile Domain, Public, Private -Enabled False ```` <br>
* verificamos  ````Get-NetFirewallProfile | Select-Object Name, Enabled````  <br>
<img width="792" height="211" alt="image" src="https://github.com/user-attachments/assets/7ae9c8ca-31e3-460b-a239-6321724e657b" /> <br>

* EN Powershell escribimos  el comando  para añadir los servidores a la lista trustedHosts
  ```` Set-Item WSMan:\localhost\Client\TrustedHosts -value "192.168.1.31" ```` <br> 
<img width="810" height="142" alt="p2" src="https://github.com/user-attachments/assets/ef26c63f-4b16-4b9e-8e07-598de70305b4" /> <br>
* Para añadir sin sobreescribir  escribimos esto ```` Set-Item WSMan:\localhost\Client\TrustedHosts -value  "$existing, 192.168.1.32" ```` <br>

* Creamos un Usuario ```` $Password= Read-Host -AsSecureStringg ```` <br>
  Introduciomos  la contraseña del core
<img width="790" height="67" alt="P4" src="https://github.com/user-attachments/assets/81b55b0b-e7a6-4014-8c18-f8db3e5191aa" /> <br>

* ```` New-LocalUser "admin_{jf}" -Password $Password -FullName " admin_{jfc}"```` <br>
<img width="807" height="103" alt="P5" src="https://github.com/user-attachments/assets/f43d7de5-7ded-46ce-b1a9-c372b612473e" /> <br>

* Agregamos el usario al grupo Administradores ```` Add-LocalGroupMenber -Group "Administradores" -Member "admin-{jf}" ```` <br>

## 4.Configuración del acceso remoto sobre HTTPS
* Generamos un certificado  ``` New-SelfSignedCertificate -DnsName "192.168.1.31" -CertStorLocation Cert:\LocalMachine\My\ -KeyLength 2048 ```  <br>
<img width="639" height="220" alt="p7" src="https://github.com/user-attachments/assets/60b7f762-d086-4f6b-bbd7-613ce15f6369" /> <br>

* Creamos el nuevo listener HTTPS ```` New-Item -Path WSMan:\localhost\Listener -Transport HTTPS -Addres * -CertificateThumbPrint  ```` <br>
<img width="811" height="262" alt="p8" src="https://github.com/user-attachments/assets/0a0fe547-3f9c-449b-9f4d-d2b07602afeb" /> <br>

* Si necesitamos borrar el listener, porque tenemos algun error  ``` winrm delete winrm/config/Listener?Address=*+transport=HTTPS ``` <br>

* Despues de haber creado el Listener Verificamos que el puerto de HTTPS Esta escuchando
``` wirnm enumerate wirnm/config/Listener ``` <br>
<img width="486" height="295" alt="p9" src="https://github.com/user-attachments/assets/ad5916e9-1d33-462d-92c6-5189aaea699a" /> <br>

* Exportamos el certificado a un archivo ``` Export-certificate -Cert Cert:\LocalMachine\My\ECCA531299095477CF046AD4A00A2C0E53BAD7D9 -FilePath  C:\servercert.cer```
